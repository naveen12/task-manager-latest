## Brand & Style

This design system targets high-performing professionals, creators, and individuals requiring acute temporal awareness and frictionless task execution on mobile devices. The brand identity fuses high-velocity focus with mindful calm, transforming daily routines, alarms, and deep-work sessions into tactile rituals.

The visual direction centers on **Dark Glassmorphism & High-Precision Glow**. Layered against an ultra-dark obsidian foundation, components leverage translucent surface planes, delicate luminous keylines, and hyper-saturated accent glows. The overall aesthetic balances the precision of luxury chronometry with the fluid responsiveness of modern native interfaces.

## Colors

The color architecture is built strictly for dark-mode-first environments, maintaining precise contrast ratios and visual ergonomics during both midday light and late-night focus sessions.

- **Obsidian & Charcoal Canvas**:
  - `Canvas Base`: `#090A0F` (True deep obsidian for root window backgrounds)
  - `Surface Tier 1`: `#12141F` (Charcoal container surface for elevated layouts and navigation bars)
  - `Surface Tier 2`: `#1A1D2D` (Card and modal surfaces)
  - `Surface Tier 3`: `#22263A` (Sub-elements, inner chips, input backgrounds)

- **Semantic Glow Accents**:
  - `Primary (Focus & Tasks)`: `#6366F1` (Electric Indigo) scaling to `#818CF8` (Neon Violet) for active timelines, active toggles, and critical primary actions.
  - `Secondary (Urgency & Alarms)`: `#F59E0B` (Luminous Amber) blending into `#F97316` (Sunset Coral) for impending alarms, time-critical alerts, and running countdown timers.
  - `Tertiary (Routines & Success)`: `#10B981` (Vibrant Emerald) fading to `#34D399` (Mint) for completed intervals, daily streak records, and healthy habit milestones.

- **Text & Translucency**:
  - `Text Primary`: `#F8FAFC` (100% white-slate high contrast)
  - `Text Secondary`: `#94A3B8` (Subtle muted slate)
  - `Text Tertiary`: `#64748B` (Inactive labels, timestamps)
  - `Border Subtle`: `rgba(255, 255, 255, 0.08)` (Signature glass stroke)
  - `Glass Fill`: `rgba(26, 29, 45, 0.70)` (Backdrop-filtered surface fill)

## Typography

The typographic hierarchy pairs **Plus Jakarta Sans** for expressive, geometric headers and temporal markers with **Inter** for ultra-legible body text and UI labels.

- Use `display-hero` exclusively for primary active clock readouts, elapsed time chronometers, and morning greeting locks. On mobile screens, scale down to `display-hero-mobile`.
- For digital counters, countdowns, and running stopwatches, enforce tabular figures (`font-variant-numeric: tabular-nums`) on `timer-mono` and `body-md` to eliminate jitter during active ticks.
- Use `label-sm` with full uppercase transformation for status pills, category markers, and day-of-week abbreviations.

## Layout & Spacing

This design system uses a fluid column layout with fixed gutter margins calibrated for direct thumb reach zones on handheld devices.

- **Mobile (<600px)**: 4-column layout, `margin` of `1.25rem` (20px), `gutter` of `1rem` (16px). All interactive actions must respect a minimum bottom clearance of `2rem` above the system navigation line.
- **Tablet / Large Foldables (>=600px)**: 8-column layout, `margin-tablet` of `2rem` (32px), `gutter-tablet` of `1.5rem` (24px). Timers and task lists reflow into a two-pane master-detail arrangement.
- **Vertical Rhythm**: Base modular unit is `4px` (`0.25rem`). Card padding follows `space-md` for standard cells and `space-lg` for active timer cards. Gap spacing between list tiles strictly adheres to `space-sm` (8px) to form cohesive daily agendas.

## Shapes

The design system embraces an ultra-modern pill-shaped geometry (`roundedness: 3`) to match high-end hardware profiles and facilitate intuitive gestures.

- Base buttons, badges, filter chips, and segmented indicators use full pill curvature (`border-radius: 9999px`).
- Small items (inputs, list items) use `1rem` (16px) corner radius.
- Cards, persistent sheets, and modal wrappers use `rounded-lg` (`2rem` / 32px) with smooth corner smoothing (continuous squircle curvature) to create an organic, premium contour.

## Components

- **Buttons**:
  - *Primary Action*: Pill-shaped (`border-radius: 9999px`), gradient fill from `#6366F1` to `#818CF8`, white bold text, subtle inner top highlight (`1px inset rgba(255,255,255,0.3)`), ambient indigo glow. Minimum touch target: 48px height.
  - *Secondary / Glass Button*: Semi-transparent obsidian fill (`rgba(255, 255, 255, 0.05)`), border `1px solid rgba(255, 255, 255, 0.10)`, text color `#F8FAFC`.
  - *Urgent Button (Alarm Dismiss/Snooze)*: Coral amber background (`#F59E0B`), high-contrast dark text `#090A0F`.

- **Pill Segmented Controls**:
  - Encased in a single track container (`#12141F`, border `1px solid rgba(255,255,255,0.06)`).
  - Selected tab floats with a glowing glass pill surface (`#1A1D2D`), bordered by `rgba(255,255,255,0.12)`, text `#F8FAFC`. Non-active items remain transparent with `#94A3B8`.

- **Cards (Task & Alarm Items)**:
  - Formed from translucent glass (`rgba(26, 29, 45, 0.70)`), inner border `1px solid rgba(255, 255, 255, 0.08)`, corner radius `2rem`.
  - Contains an optional left temporal indicator strip tinted by category (Indigo for Focus, Amber for Alarm, Emerald for Routine).
  - Tap states trigger a subtle scale contraction (`scale(0.985)`) accompanied by haptic feedback.

- **Glowing Gradient Toggles**:
  - Track: Width 52px, height 32px, pill-shaped. Inactive: `#1A1D2D` with subtle border.
  - Active: Gradient fill (`#6366F1` to `#818CF8`) with ambient glow `0 0 12px rgba(99, 102, 241, 0.5)`.
  - Thumb: 26px circle in pure white (`#FFFFFF`), inset shadow for a tactile physical bead look.

- **Checkboxes & Habit Radios**:
  - Radios/Checkboxes utilize circular tactile rings (24px).
  - Unchecked: 2px border in `rgba(255, 255, 255, 0.20)` over transparent background.
  - Checked: Spring-animated radial expansion to Emerald (`#10B981`) with a crisp white checkmark and emerald ring glow.

- **Chips & Badges**:
  - Height 24px–28px, full pill curve, micro typography (`label-sm`).
  - Background: 12% alpha tint of the respective accent (e.g., `rgba(245, 158, 11, 0.12)` for urgency), border `1px solid rgba(245, 158, 11, 0.30)`, foreground matching the pure accent color.

- **Input Fields**:
  - Height 52px, pill or `1rem` rounded rectangle. Surface `#161926`, border `1px solid rgba(255, 255, 255, 0.08)`.
  - Focused state: Border transitions to `#6366F1`, supported by an outer ambient ring `0 0 0 3px rgba(99, 102, 241, 0.25)`. Text sits in `body-md` (`#F8FAFC`).

- **Temporal Wheel & Time Scroller (Domain-Specific)**:
  - Radial or vertical scrolling drum selector for alarm setting. Center selection flanked by dual luminous horizontal boundary rules (`rgba(99, 102, 241, 0.4)`), magnifying active digits using `display-hero-mobile`.
